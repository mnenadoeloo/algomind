# AlgoMind

**AlgoMind** — AI-агент для подготовки к алгоритмическим задачам и техническим собеседованиям.

Вместо того чтобы выдавать готовый ответ, AlgoMind помогает разобраться в логике решения: задаёт наводящие вопросы, объясняет идею и оценивает сложность, а по истории попыток находит слабые места в знаниях и предлагает, что тренировать дальше.

## Возможности

- **Пошаговый разбор задачи** - подсказки нарастающей глубины (идея -> структура данных -> алгоритм -> код), без спойлера решения по умолчанию.
- **Анализ решения пользователя** - корректность, граничные случаи, оценка временной и пространственной сложности.
- **Диагностика слабых мест** - профиль навыков по темам (графы, DP, два указателя, …) на основе истории попыток.
- **Персональный план тренировки** - подбор следующих задач под текущий уровень.

## Быстрый старт для разработки

Требуется Python 3.11+.

```bash
python -m venv .venv && source .venv/bin/activate
pip install ruff pre-commit pytest
pre-commit install          # включить хуки на commit
pre-commit run --all-files  # прогнать вручную
ruff check . && ruff format --check .
pytest
```
